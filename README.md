# auto_fill

The Auto_Fill extension is a powerful tool designed to automate the process of filling input fields on websites with various types of data. Whether you need to quickly populate forms with email addresses, passwords, text, or even datetime values, this extension has got you covered.

## Features

- **Auto-filling Input Fields**: The extension automatically detects input fields on websites and fills them with appropriate data based on their type.
- **Multiple Data Types**: The extension supports various data types, including email addresses, passwords, plain text, and datetime values.
- **Customizable Settings**: Users can customize the extension's behavior and choose which data type to use for each input field.

## Usage

1. Visit a website that has input fields you want to populate.
2. Click on the Auto_Fill extension icon in your browser's toolbar.
3. Input the text length (optional)
4. Click the button and the extension will automatically detect the input fields on the page and it will populate with appropriate data based on its type.
